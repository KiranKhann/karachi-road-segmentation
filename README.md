# Segmentation assignment — UNet/UNet++, Cityscapes → Karachi, CVPR 2025 & ICML 2024

Start with **[REPORT.md](REPORT.md)** — it contains the paper summaries, the Cityscapes observations, the
experimental results of both notebooks and the state‑of‑the‑art survey.

```
notebooks/
  01_unet_unetpp_framework.ipynb      UNet & UNet++ from scratch, reusable for any images+masks dataset (executed on Kvasir-SEG)
  02_karachi_road_segmentation.ipynb  Cityscapes-trained SegFormer + Mask2Former on 22 Karachi road photos, privacy pass, analysis (executed)
data/
  karachi_raw/        openly licensed Karachi photos from Wikimedia Commons + MANIFEST.csv (author, licence, source URL)
  karachi_anon/       face / plate / head anonymised copies — the only images used in figures
  karachi_pseudo/     confidence-filtered 19-class pseudo-labels exported by notebook 02 (for fine-tuning with notebook 01)
  anonymizer/         OpenCV-Zoo YuNet face + LPD-YuNet plate detectors (ONNX), used by notebook 02
  kvasir_seg_download/Kvasir-SEG/   1,000 polyp images + masks (CC BY 4.0), used by notebook 01
outputs/
  unet_vs_unetpp/     checkpoints, histories, results.csv, curves.png, predictions.png
  karachi/            overlays, per-image stats, traffic-mix & confidence charts, confusion matrix, summary.json
```

## Running the notebooks

Tested with Python 3.14, PyTorch 2.14 + CUDA 12.6, Transformers 5.19, OpenCV 5.0 on a 6 GB RTX 4050 (CPU works, slower).

```bash
pip install -r requirements.txt
```

Open either notebook in Jupyter / VS Code and *Run All*, or execute headless:

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/01_unet_unetpp_framework.ipynb
```

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/02_karachi_road_segmentation.ipynb
```

* Notebook 01 downloads Kvasir‑SEG (46 MB) on first run if `data/kvasir_seg_download` is missing, and falls back to a synthetic dataset when offline. To use **your own data**, edit only the `Config` cell (paths, `num_classes`, `img_size`, `epochs`).
* Notebook 02 pulls the two Hugging Face checkpoints (~300 MB) on first run. To analyse **your own road photos**, drop JPEGs into `data/karachi_raw/` and add a row per file to `MANIFEST.csv` (photograph from public space, avoid framing individuals, keep the anonymisation cells on).

## What is (not) in the repository

To keep the repo small and privacy‑safe, the following are **not committed** (see `.gitignore`) and are recreated locally:

| excluded | how to get it back |
|---|---|
| `data/kvasir_seg_download/` (46 MB, CC BY 4.0) | notebook 01 downloads it automatically |
| `data/karachi_raw/*.jpg` (un‑anonymised originals) | `python scripts/fetch_karachi_images.py` re‑downloads them from the Commons URLs in `MANIFEST.csv` |
| `outputs/**/*.pt` (trained checkpoints, ~70 MB) | re‑run notebook 01 (≈ 15 min on a 6 GB GPU) |
| `data/karachi_pseudo/`, per‑image label PNGs | regenerated by notebook 02 |

Committed: both executed notebooks (with figures), `REPORT.md`, the anonymised Karachi images (`data/karachi_anon/`, CC BY / CC BY‑SA / FAL — attribution in `MANIFEST.csv`), the OpenCV‑Zoo detector weights (Apache‑2.0), and the small result tables/charts in `outputs/`.
